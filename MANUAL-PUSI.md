# Estrutura do Projeto

## Arquivos principais

- `index.html` → Estrutura do site.
- `style.css` → Aparência (cores, tamanhos, espaçamentos e responsividade).
- `imagens/` → Todas as imagens utilizadas no site.

## Regra de trabalho

Sempre trabalhar por **CAIXAS**.

Para cada alteração informar:

- 📦 Caixa.
- 📍 Linha.
- 🗑️ O que apagar.
- 📋 O que colar.

Nunca alterar outras caixas sem necessidade.
